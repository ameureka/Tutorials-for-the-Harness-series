# 001 AI 时代第一步动起来：从 Prompt 走向工程化交付

> **本讲定位**：破除对纯提示词工程的盲目迷信，搭建首个可运行的 AI 最小可行产品（MVP）。  
> **主讲导师**：王亚林 ｜ **开源协议**：CC-BY-4.0  

---

## 🎯 一、 核心要点速览

1. **破除“提示词神话”**：
   * 很多初学者误以为大模型开发就是写一段长长的小说式 Prompt。然而在真实软件开发中，没有工程约束的 Prompt 极易因模型版本微调而失效。
   * 软件的核心在于**确定性**，必须以代码脚手架（Harness）来包裹模型的不确定性。
2. **现代 AI Agent 的执行三要素**：
   * **感知 (Perception)**：结构化入参清洗、上下文检索增强（RAG）；
   * **推理 (Reasoning)**：规范驱动的任务拆解（Spec-Driven Decomposition）；
   * **行动 (Action)**：具备重试和异常熔断的外部函数与 API 调用。
3. **极速构建最小可行产品 (MVP)**：
   * 选定一个明确的微小闭环场景，不要一开始就做“全能助手”；
   * 建立标准的前后端轻量接口契约，让系统先具备端到端的可用性。
